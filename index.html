Connect the real Google Maps

This app runs on the official Google Maps JavaScript API — Google's own map, satellite view and directions, with the dashcam floating on top. It needs your Google Maps API key (billing enabled on your Google account):

  1. Open the Google Maps Platform console and pick (or create) your project.
  2. Enable billing on the project, then enable: Maps JavaScript API, Directions API, Places API and Geocoding API.
  3. Under Credentials, create an API key, copy it, and paste it here.

Your key is stored only on this device (local storage) and sent only to Google to load the map. You can replace or remove it any time from the dashcam ••• menu → API key settings.

Google Maps couldn't load

Google rejected the request.

Nothing is faked here — without a working key there is no map. Check in Google Cloud Console that:

  1. Billing is enabled on the project that owns the key.
  2. The Maps JavaScript API (plus Directions, Places and Geocoding) is enabled.
  3. The key's restrictions allow this website as an HTTP referrer.
